版本 2.1.6（2026-11-08）
  - 模拟配装：双持投掷时两把武器的攻速改为相加（以前取平均，攻击速度和每秒出手算少了），双持近战仍取平均；两种都和游戏里人物面板实测一致。
  - 模拟配装：面板攻击速度的持握系数改用精确值（例如单手 19/30、法杖 209/320），以前四舍五入到三位小数，个别配置会和游戏差 1%。
  - 模拟配装：平均伤害值按游戏面板的算法分两组（这把武器本身的伤害、其他来源加上的伤害，例如首饰上的固定附伤和技能、增益）各自去掉小数再相加，以前合在一起取整，有时多 1；DPS 跟着变（游戏里实测）。
  - 模拟配装：武器和盾牌底材自带的护甲不再加到各部位，游戏里不计（游戏里实测）；镶在上面的镶嵌物照算。
  - 模拟配装：判断穿不穿得上时，补上护甲、盾牌、杖类、所有武器这些分类的属性需求降低和「物品等级要求降低」，减免后的需求四舍五入为整数再比较；装备详情里显示减免后的需求（游戏里实测）。
  - 模拟配装：法力预留减免超过 100% 时预留为负，可用法力高于上限，现在按这样计算（以前按 0 算；游戏里实测）。
  - 模拟配装：内丹专精「潜力万能药」补上喝药后的增益（生命 / 法力恢复，毒素、流血、生命吸取抗性），以前勾上什么都不加（游戏里实测）；「苦果」改标为攻击命中时触发的被动；「互相折磨」的说明里列出它传播给周围敌人的减益；已经用不到的旧版金蟾祝福增益不再能加点。
  - 模拟配装新增选项「几率抗性 / 护甲按游戏面板折算」：勾上后「X% 机会」的抗性和护甲按 值 × X% 计入，和游戏人物面板显示一致；不勾时照旧只算一定生效的部分。
  - 新增选项「按手机版（安卓 / iOS）的需求公式」：安卓 / iOS 的装备需求公式和 PC 不同（例如护甲力量每级 7.5，PC 是 7.75；史诗冰鳞 PC 492、手机 478），勾上后装备页、筛选条件和模拟配装都按手机版算需求。
  - 修正：装备本身写死的智力需求，在选了词缀以后会被公式值顶替，现在照用写死的值。
  - Android 版同步到 2.1.6。

Change log

Version 2.1.6 (2026-11-08)
  - Build simulator: dual thrown weapons now add both weapons' speed (it used the average, under-reading attack speed and attacks per second); dual melee still uses the average. Both match the character sheet in game.
  - Build simulator: the grip factors of the sheet attack speed use exact values (e.g. 19/30 for one hand, 209/320 for a staff); the old 3-decimal values could put some builds 1% off the game.
  - Build simulator: average damage follows the game sheet: the weapon's own damage and damage added by everything else (flat damage on jewelry, skills, buffs) drop their decimals separately before being added (it used one rounding and could show 1 more); DPS follows (tested in game).
  - Build simulator: the flat armor on a weapon or shield base no longer adds to every body part; the game does not count it (tested in game). Relics in them still count.
  - Build simulator: requirement checks now include the category reductions (armor, shield, staff, all weapons) and "item level requirement" reduction, and round the reduced requirement to a whole number before comparing; item details show the reduced requirement (tested in game).
  - Build simulator: with more than 100% energy reserve reduction the reserve goes negative and usable energy exceeds the maximum; now counted that way (it was floored at 0; tested in game).
  - Build simulator: Neidan "Potion Buff" now adds its buff after drinking (health / energy regeneration, poison, bleeding and life leech resistance; it added nothing before; tested in game); "Consequences" is labelled a passive that fires on hit; "Spreading Rot" lists the debuff it spreads to nearby enemies; the unused old Golden Toad buff can no longer take points.
  - New build simulator option "Chance resistances / armor as the game sheet shows them": ticked, "X% chance" resistances and armor count as value × X%, matching the game's character sheet; unticked, only guaranteed values count as before.
  - New option "Use the mobile (Android / iOS) requirement formulas": Android / iOS use different item requirement formulas from PC (e.g. armor strength 7.5 per item level, PC 7.75; epic Fjord armor: PC 492, mobile 478); ticked, the equipment page, filters and build simulator use the mobile requirements.
  - Fix: an item's fixed Intelligence requirement was replaced by the formula value once affixes were chosen; the fixed value is used now.
  - Android app updated to 2.1.6.

Version 2.1.5 (2026-11-08)
  - A summon ability above that skill's top level now counts as the top level, with a note (e.g. the Guardian Stones' Destruction, the Core Dweller's Concussive Blow; tested in game).
  - Daggertooth: its granted skill fires but launches no projectile and deals no damage; noted in its details (tested in game).
  - Build simulator: the self buffs that Bristleback Helm, Skyrta of Orvar-Oddr, Will of Horus, Axe of King Budli, Spear of Nemetona and Hrunting cast when attacking can be ticked under item-granted buffs and count in the character sheet (Bristleback Helm tested in game).
  - Build simulator, item-granted buffs: 9 skill icons added (Frenzy, Artemis' Battle Dance, Demeter's Bounty, Lion's Roar, Shield of Destiny, Jade Emperor's Mau-D'uyhn, Mirror Wall, Kheprer's Sting, Kwoll Blast); buffs that have no icon in the game (Wild Hunt's pet magic resistance, Way of the Monk, Ascension) show the item's icon; when folded, buffs that are on get an accent frame, so on / off is easy to see (mastery buffs and shrine curses too).

Version 2.1.4 (2026-11-08)
  - Skills granted by items, "+N to" bonuses and summon skills show their in-game names (e.g. "+2 / +5 to Nature's Wrath" on Might of Apep and Infused Might of Apep); skills that have no name in the game read "unnamed passive" / "unnamed skill"; items with no in-game name are listed as "Unnamed helm #1" and so on.

Version 2.1.3 (2026-11-08)
  - Item details' double-affix share line: quest monsters use the same bonus as bosses (numbers unchanged).
  - Corrected Scatter Shot and other projectile upgrades: with a bow the Marksmanship arrow also gets Scatter Shot's damage, a thrown weapon does not; the fragments are the same for both (tested in game).
  - Fixed item-granted charged attacks (Onslaught, Calculated Strike, Psionic Touch, Rune Weapon; 12 items): they used to say "0% chance on a normal attack"; you actually set them to the left mouse button and hits build charge (tested in game).
  - Adamantine Sickle of Kronos: tested in game, it does not drop after the normal Typhon's Prison scene; the source tag now reads "unconfirmed".
  - Skill tree: an upgrade that still partly works with the current weapon (e.g. Puncture Shot with a thrown weapon) now shows the working (green) ring; the parts that do not work are still marked red in its details.
  - Build simulator: holding the up / down arrow of a number box (mastery bar, attribute points, skill points) repeats again.
  - Character: new "Just enough for gear" button next to Reset points. It sets Str / Dex / Int to the fewest points that keep every equipped piece on; attributes and requirement reduction from gear, set bonuses and masteries count, so what they cover is returned as unused. Health and Energy stay as they are.
  - Corrected quest reward difficulties: some quests give a different reward table on each difficulty (mostly Ragnarök side quests such as The Warrior Princess, White Gold, Squabbling Merchants, The Restless King). The Epic and Legendary tables were also counted on Normal, so items such as Wild Hunt, Key of Elysium and Odysseus' Armor showed Normal quest rewards. Quests now count only the table they give on each difficulty; 672 source lists changed.
