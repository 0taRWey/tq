泰坦之旅装备资料库 · 版本 2.2.10
整理：贴吧用户_0taRWey

网址：https://0tarwey.github.io/tq/ （首页是英文页，中文页是 zh.html；打开首页时按浏览器语言自动进入对应页面，右上角可切换）。
另有德、法、西、意、巴西葡语、波兰、捷克、俄、乌克兰、日、韩 11 种语言的页面（de.html … ko.html，文字取自游戏自带的该语言文字，界面暂用英文）。
英文版的物品、词缀、技能、属性文字取自游戏自带英文文字。
网站版完整打开过一次后，没网也能用。手机：用 Safari / Chrome 打开网址 → 分享或「⋮」→「添加到主屏幕」，以后点主屏幕上的「TQ 装备资料库」图标打开，全屏。
电脑：Edge / Chrome 可以「安装此站点为应用」。
iPhone / iPad「文件」App、微信等里直接点开 .html 文件是预览，不运行脚本，属性列表会是空的。
2.2.9 是最后一个 Android 安装包；网页版压缩包从 2.2.9 起不再提供。以后请直接用网站版。
更新内容见 更新日志.txt。

数据对应 PC 版《泰坦之旅：不朽之王》（Titan Quest Anniversary Edition 2.10，含全部资料片）。
手机版（iOS / Android）需求公式的系数不同，其余数据相同；网页右上角的「PC / 手机」开关切到手机可按安卓 / iOS 看需求。

Website: https://0tarwey.github.io/tq/ (English at the root, Chinese at zh.html; the root opens the page in the browser's language; switch at the top right).
