Titan Quest Database · version 3.0.4
Compiled by 贴吧用户_0taRWey

Website: https://0tarwey.github.io/tq/ (English at the root, Chinese at zh.html; the root opens the Chinese page when the browser is set to Chinese; switch at the top right).
Maps: https://0tarwey.github.io/tq/map/ ("Maps" at the top right; all 7 chapters, 55 teleport areas).
From 3.0.1 the site is in Chinese and English only. The pages in 11 more game languages (German, French, Spanish, Italian, Brazilian
Portuguese, Polish, Czech, Russian, Ukrainian, Japanese, Korean) were removed; their old addresses open the English page.
After one full visit it also works offline. Phones: open the address in Safari / Chrome → Share or "⋮" → Add to Home Screen; it then opens
full screen from the home-screen icon. Computers: "Install this site as an app" in Edge / Chrome.
File previews (iOS Files app, chat apps) do not run scripts.
2.2.9 is the last Android app, and from 2.2.9 there is no zip download; use the website. See 更新日志.txt for the change log.
